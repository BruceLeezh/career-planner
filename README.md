# 职引 · 大学生职业规划系统（Career Compass）

> **来源声明**：本项目基于 [juice-butterfly/career-planner](https://github.com/juice-butterfly/career-planner) 二次开发与完善，
> 在此基础上补齐了培养方案全量数据、静态演示构建与 AI 求职能力。

面向大学生的职业规划工具：从 31 题四维职业测评出发，串起专业培养方案、竞赛、证书、岗位路线、
简历与面试准备，并用 AI 给出可执行的建议。

## 功能概览

| 模块 | 内容 |
|---|---|
| 职业测评 | 31 题四维（兴趣 / 能力 / 性格 / 价值观）计分，含反向题与信度校验，输出双雷达图与霍兰德代码 |
| 本校资料 | 21 个学院、86 个本科专业培养方案（7,644 门课程），逐条标注官方来源章节 |
| 深造中心 | 保研 / 考研 / 留学三条路径，含竞争力定位与院校分层建议 |
| 竞赛与证书 | 122 项竞赛、25 本证书，按专业推荐并一键加入规划 |
| 岗位百科 | 11 个行业、50 个岗位，含四年成长路线与薪资分位 |
| 求职准备 | 简历工作台（诊断 / 生成 / 润色）、模拟面试、考公选调 |
| 我的规划 | 阶段化事项、打卡与成长曲线 |

## 目录结构

```
01-前端源码/      Vue 3 + Element Plus + ECharts
02-后端源码/      Express + SQLite（建表、种子、测试）
03-参考文档/      项目说明与平台移植手册
05-工具脚本/      数据抓取、导出、审计与验证脚本
06-审计报告/      历次安全与质量审计结论
static-dist/      静态演示版（本地数据适配器，无需后端）
```

## 快速开始

后端：

```bash
cd 02-后端源码
cp .env.example .env      # 填写 JWT_SECRET 与 AI_* 配置
npm install
npm run seed              # 生成演示账号，口令仅在控制台打印一次
node src/server.js
```

前端：

```bash
cd 01-前端源码
npm install
npm run dev               # 代理到 http://localhost:3000
```

静态演示版（无后端，数据来自 `05-工具脚本/export-vue-static.mjs` 导出的快照）：

```bash
cd static-dist
python -m http.server 8080
```

## 数据来源

培养方案数据取自中南财经政法大学本科生院《本科专业全程培养方案（2024 版）》上下册官方文件，
经 PDF 文本抽取、按「专业（类）名称」锚点切分、课程号与学分校验后入库，未做任何虚构补充。
未单独发布方案的 2025/2026 新增专业，在库中明确标注「参照某专业方案」，并在页面展示来源。

## 脱敏说明

本仓库**不包含任何真实密钥、账号口令、证件号、手机号、内网地址或真实业务数据**：

- `.env`、`*.sqlite`、`*.db` 不入库，仅保留 `.env.example` 占位模板
- 种子与 E2E 脚本中的口令改为环境变量读取
- 演示手机号统一 `13800000000`，邮箱统一 `example.com` 域
- 参赛提交材料（含真实姓名与学工号）、技能包、上架包均不入库
- 本机绝对路径全部改为 `HOME` / `USERPROFILE` 拼接

详细清单与复核方式见 [脱敏与配置说明.md](./脱敏与配置说明.md)。
